# Launch plan — blocked pending product readiness

## Before beta
- Complete must-have features and all S1/S2 fixes.
- Run accounting reconciliation and backup/restore tests.
- Prepare privacy policy, terms, support contact and data-safety disclosures.
- Recruit opt-in beta testers; do not invent users or testimonials.

## Beta
- Test multiple Android versions and screen sizes.
- Collect consented feedback on invoices, stock costing, statements, import and restore.
- Track crashes and failed data operations without logging financial personal data.
- Publish known limitations.

## Public launch gate
- Store listing lint passes.
- Brand clearance is reviewed.
- Privacy and compliance disclosures match actual behavior.
- No open S1/S2 issues.
- Release build is signed with a user-owned production key; never ship a debug key.
