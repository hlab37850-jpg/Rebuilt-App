# Brand direction

## Working name
**محاسب بيه** remains the working label already used in the native rewrite. It is not trademark-cleared. Alternatives for later screening: مِعيار، رَصيد، دَفاتر، سِجل، مِيزان. No name is marked available.

## Positioning
Arabic-first, offline-first accounting for small businesses that need understandable balances, stock movements and traceable invoices.

## Palette proposal
- Primary emerald/teal #087F70 — intentionally different from the original blue identity.
- Background #F3F6FC; surface #FFFFFF; text #202A41; muted #687386.
- Danger #B42318; success #16794B.

Tokens are provisional and must pass contrast checks. The existing rewrite still uses blue; no UI recoloring was done in this documentation phase.

## Voice
Clear, trustworthy, practical. Explain money effects; show totals and currency; confirm destructive actions; label estimates. Do not promise perfect accounting, hide fees, invent testimonials or claim compliance without verification.

## Logo brief
Create an original ledger/balanced-entry symbol, not a copy of the reference icon. Must work at 16px and 1024px. Deliver SVG source, Android adaptive icon assets and social image. Do not reuse original shapes, logos, assets or fonts.

## Clearance checks — NOT RUN
USPTO, EUIPO, WIPO, Yemen/target-market legal review, domain registrar, Play/App Store, social handles and general web search. Obtain trademark advice before paid launch.
